## 🏗️ Arquitectura del Proyecto
El ecosistema de la aplicación se divide en:
- **Backend** (`/backend`): API construida con NestJS, Prisma ORM y base de datos PostgreSQL (vía Docker en el puerto 5433).
- **Web Admin** (`/apps/admin`): Panel de administración web construido con Next.js.
- **Web Cashier** (`/apps/cashier`): Interfaz para cajeros construida con Next.js.
- **App Móvil** (`/apps/mobile`): Aplicación para clientes finales construida con Expo y React Native.
- **Entregables** (`/aplicaciones`): Carpeta de binarios compilados (Ej: APKs).
