# Reglas Base de Antigravity para Divisas

> **⚠️ REGLA CRÍTICA DE MEMORIA (LONG-TERM MEMORY)**
> Si el usuario te pide "Retomar Divisas", "Abre el historial de Divisas", o algo similar que indique que se está reanudando el trabajo en este proyecto:
> 1. **TU PRIMER PASO OBLIGATORIO** antes de hacer cualquier otra cosa (y antes de emitir un plan de implementación) es leer el archivo `MEMORY.md` que se encuentra en la raíz de este proyecto.
> 2. Una vez leído, debes saludar al usuario, darle un brevísisimo resumen de en qué nos quedamos (basado en el archivo) y preguntarle con qué de la lista de "Siguientes Pasos" vamos a empezar hoy.
> 3. Al finalizar cada sesión de trabajo importante, o antes de cerrar, recuerda o pregúntale al usuario si debes actualizar el archivo `MEMORY.md` con los logros del día.
